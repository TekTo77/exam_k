# Чудо Обувь — полный проект

Полная простая инструкция — **INSTRUCTION.md** в этой папке.

- `python main.py` — полное приложение.
- `python import_db.py` — отдельный импорт Excel.
- `python Excel_Preparation/main.py` — отдельный редактор.
- Подключение — `postgres_connection.json` в корне.
- Дизайн — `design.py` в корне.

Обычный PostgreSQL и Docker поддерживаются. Перед запуском установи
зависимости из `requirements.txt`, запусти сервер и проверь подключение.
В приложенном Docker-примере данные временные.


Структура: `interface/` — экраны; `storage/` — PostgreSQL;
`excel_importer/` — импорт; `tools/` — вспомогательные команды.
В модульном комплекте эти папки находятся внутри соответствующих модулей.
Подробная карта файлов — раздел 13 в `INSTRUCTION.md`.
